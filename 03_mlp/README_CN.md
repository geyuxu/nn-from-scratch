# 03 - 多层感知机 (MLP)

[English](README.md)

## 目标

实现多层神经网络，包含隐藏层和非线性激活函数。

## 核心原理

### 1. 从逻辑回归到 MLP

| | 逻辑回归 | MLP |
|---|---|---|
| 结构 | 单层 | 多层 |
| 表达能力 | 线性决策边界 | 非线性决策边界 |
| 激活函数 | Sigmoid（仅输出） | ReLU（隐藏层）+ Sigmoid（输出层） |
| 参数 | W, b | W1, b1, W2, b2, ... |

### 2. 模型结构

```
输入 → 隐藏层 → 输出层 → 预测
  X  → ReLU(X@W1+b1) → Sigmoid(H@W2+b2) → y_pred
```

两层 MLP（一个隐藏层）：
```python
def forward(X):
    h = relu(X @ W1 + b1)      # 隐藏层 + ReLU
    return sigmoid(h @ W2 + b2) # 输出层 + Sigmoid
```

### 3. 激活函数

**ReLU（线性整流单元）**
```python
relu(t) = max(0, t)
```
- 简单高效
- 缓解梯度消失问题
- 隐藏层常用激活函数

**Sigmoid**
```python
sigmoid(t) = 1 / (1 + exp(-t))
```
- 映射到 (0, 1) 概率
- 二分类输出层使用

### 4. 隐藏层的作用

- **万能近似**：一个隐藏层的 MLP 可以逼近任意连续函数
- **特征学习**：隐藏层学习中间表示
- **非线性边界**：可以分离线性不可分的数据

### 5. 反向传播

链式法则将梯度传播到所有层：

```
∂Loss/∂W1 = ∂Loss/∂y_pred × ∂y_pred/∂h × ∂h/∂W1
```

PyTorch 的 autograd 通过 `loss.backward()` 自动完成。

## 训练流程

```python
for epoch in range(epoch_count):
    # 1. 前向传播（两层）
    h = relu(X @ W1 + b1)
    y_pred = sigmoid(h @ W2 + b2)

    # 2. 计算损失（交叉熵）
    loss = -(y_true * log(y_pred) + (1 - y_true) * log(1 - y_pred)).mean()

    # 3. 反向传播
    loss.backward()

    # 4. 更新所有参数
    W1 -= lr * W1.grad
    b1 -= lr * b1.grad
    W2 -= lr * W2.grad
    b2 -= lr * b2.grad
```

## 乳腺癌分类结果

### 网络架构

```
输入 (30 特征) → 隐藏层 (32 单元, ReLU) → 输出层 (1 单元, Sigmoid)
```

- 隐藏层大小：32
- 学习率：0.01
- 训练轮数：3000

### MLP vs 逻辑回归

| 指标 | 逻辑回归 | MLP |
|------|----------|-----|
| 测试准确率 | 98.25% | **99.12%** ↑ |
| 测试 F1 | 98.59% | **99.30%** ↑ |
| 错误样本 | 2 个 | **1 个** |

### 关键发现

- **Recall = 100%**：无假阴性 - 所有癌症病例都被检出
- **仅 1 个错误**：只有 1 个假阳性（FP=1）
- **相比逻辑回归有提升**：隐藏层帮助捕获非线性模式

### 为什么 MLP 更好？

1. **非线性决策边界**：可以拟合更复杂的模式
2. **特征变换**：隐藏层学习有用的中间特征
3. **更好的泛化**：更强的表达能力捕获细微差别

## 结论

MLP 在 Breast Cancer 数据集上达到 **99%+ 准确率**，相比逻辑回归有提升：

1. **隐藏层增强能力** - 即使一个隐藏层也能提升性能
2. **ReLU 激活** 使更深网络的训练更高效
3. **医学场景**：100% 召回率至关重要 - 不能漏诊
4. **权衡**：参数更多，但在小数据集上训练仍然很快
